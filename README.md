# Birthday Letter — GitHub Pages

This version is a static React/Vite site prepared for GitHub Pages. It includes the supplied photos and videos and keeps the Spotify embed.

## Publish
1. Create a GitHub repository.
2. Upload the contents of this folder to the `main` branch (not the ZIP file itself).
3. Go to **Settings → Pages** and choose **GitHub Actions** as the source.
4. GitHub will run the workflow and publish the site.
